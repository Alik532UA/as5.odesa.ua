# Одноразові скрипти

Тут лежать кодмоди, які вже відпрацювали. Вони не підключені до `package.json`
і не мають запускатися повторно.

Обидва читають і перезаписують **один захардкоджений файл** —
`src/routes/test/+page.svelte`, — тому повторний запуск на вже зміненому файлі
дасть не той результат, який дав уперше:

- `inject_galleries.cjs` — вставляв розмітку галерей у сторінку `/test`;
- `update_gallery.cjs` — оновлював уже вставлену розмітку.

Лишені в репозиторії як історія того, звідки взялася розмітка тієї сторінки.
Якщо знадобиться щось подібне ще раз — писати новий скрипт із параметром шляху,
а не запускати ці.
