# AGENTS.md — as5.odesa.ua

> **Спершу прочитай [PROJECT-CONTEXT.md](PROJECT-CONTEXT.md).** Там персональний
> шар пакета v8: профіль, реєстр префіксів сховищ на спільному origin, прийняті
> рішення з датами, свідомі відхилення й перелік того, що тут **не**
> перевіряється автоматично. Цей файл — коротка витримка для щоденної роботи.
>
> Загальні стандарти живуть у `sveltekit-canon/selection_criteria/v8`. Тут — лише
> те, що специфічне для цього репозиторію.

## Що це

Сайт школи в Одесі. Дві мови (`uk` типова, `en`), шість маршрутів,
prerendered повністю.

## Архітектура

- **Фреймворк:** SvelteKit 2 + Svelte 5 (**виключно** руни).
- **Профіль:** `static`. Серверного рантайму немає: ні form actions, ні
  `+server.ts`, ні `hooks.server.ts`. Дані — з `+page.ts` і статичного вмісту.
- **Стан:** класи-контролери в `.svelte.ts`. Module-level синглтон — панівна
  форма; `$effect` у його конструкторі кидає `effect_orphan`.
- **Сховище:** фасад `src/lib/services/storage.ts`. Прямий доступ до
  `localStorage` заборонений скрізь, окрім інлайн-скрипта першого кадру в
  `app.html` (він виконується до будь-якого модуля).
- **i18n:** `svelte-i18n`, словники — JSON у `src/lib/i18n/locales/`. Паритет
  ключів тримає інваріант `translations.test.ts`, бо тип їх не звіряє.
- **Публічна адреса:** єдине джерело — `src/lib/config/site.ts`. Ніде більше
  origin не збирається вручну.

## Локальні пастки

| Пастка | Що саме |
|---|---|
| `paths.base` = `/as5.odesa.ua` | `url.pathname` **уже містить** базу. Додавання її вдруге дає canonical у нікуди — так уже було на кожній сторінці сайту |
| Порт dev-сервера | 5193 (`as5-dev` у `.claude/launch.json` кореня GitHub) |
| Дві живі адреси, основна — **власний домен** | сайт віддається і з `https://as5.odesa.ua/` (основна, куплений домен), і з `https://alik532ua.github.io/as5.odesa.ua/` (запасна). Canonical, `og:url`, sitemap і `robots.txt` ведуть на основну; запасна лишається робочою, але в індексі не згадується |
| `paths.base` порожня, і це не помилка | база `''`, бо на власному домені сторінки в корені. Не повертай `/as5.odesa.ua`: 2026-08-15 саме через неї зібраний CSS просив шрифт за `as5.odesa.ua/as5.odesa.ua/fonts/…` — 404, і сайт показувався системними шрифтами. У коді цього не видно ніяк, лише в `build/` або в мережевій панелі |
| Шляхи в CSS — **відносні** | CSS не бачить `paths.base`, тож абсолютний шлях прив'язує стилі до однієї адреси. `global.css` тепер тримає `url('../../../static/fonts/…')`, і Vite сам переписує їх на хешовані ресурси. Абсолютний шлях від кореня тут — регрес |
| CSP | доставляється `<meta>`, бо GitHub Pages не дає ставити заголовки. У dev CSP приходить заголовком — поведінка різна (SECURITY-v8 § 6.4) |
| Дві реалізації `ErrorBoundary` | обидві вживані; не видаляй жодну, не перевіривши обидва місця |

## НЕ РОБИ

| Заборонено | Замість цього |
|---|---|
| `writable()`, `readable()`, `derived()` зі `svelte/store` | `$state` / `$derived` у класі-контролері |
| `import { page } from '$app/stores'` | `$app/state` |
| `localStorage.getItem(...)` напряму | `storage` із `$lib/services/storage` |
| `localStorage.clear()` | вибіркове видалення за префіксом — origin спільний із шістьма сусідніми проєктами |
| `{@html}` над чим завгодно | лише над власними даними, з `eslint-disable-next-line` і причиною поруч |
| `${base}/шлях` для посилань | `resolve('/шлях')` з `$app/paths` — типізований проти реальних маршрутів |
| `${base}/images/x.svg` для файлів | `asset('/images/x.svg')` |
| `toLocaleString()` без аргументу | явна локаль: без неї береться локаль **системи**, а не мова сайту |
| `any` | конкретний тип, `unknown` або дженерик |
| `as SomeType` над зовнішнім значенням | type guard: `as` нічого не звіряє |

Кожен рядок цієї таблиці — правило ESLint. Вимкнути правило можна лише разом із
записаною поруч причиною (CODE-QUALITY-v8 § 6.4.1); інваріант
`src/eslint-baseline.test.ts` падає, якщо хтось вимкне його мовчки.

## Конвенції

- **Префікс сховища:** `as5.odesa.ua_`. Єдине джерело — `src/lib/config/storage.ts`.
- **Іменування:** компоненти `PascalCase.svelte`, утиліти `camelCase.ts`,
  контролери з рунами — обов'язково `.svelte.ts`.
- **`data-testid`:** конвенція в TESTID-AND-NAMING-v8; статична перевірка —
  `src/testid-conventions.test.ts`.
- **Тести:** Vitest, файли `*.test.ts` під `src/`. Playwright тут **не стоїть** —
  не пиши файлів під нього (AI-AGENT-PITFALLS-v8 § 1.3).

## Команди перевірки

```
npm run check        # svelte-check, має бути 0 помилок
npm run lint         # eslint, має бути 0 помилок
npm test             # юніт-інваріанти
npm run build        # збірка
npm run check:build  # гейт над build/: canonical, og:image, подвоєна база, sitemap
```

**Результат треба побачити, а не припустити.** Твердження «правило виконано»
робиться після прогону, а не замість нього. Частину дефектів цього проєкту
видно **лише** у `build/` — саме тому `check:build` існує окремо
(AI-AGENT-PITFALLS-v8 § 2).
