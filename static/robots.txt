# ЖОДНОГО Disallow — і це рішення, а не пропуск (BETA-CHECKLIST § 4.0,
# `BETA-NOINDEX-OVER-DISALLOW`).
#
# Службові сторінки (`/test`, `/beta-test-checklists`) закриті `noindex` у
# власному HTML, а не забороною обходу. Заборона обходу означає, що краулер
# сторінку НЕ ЗАВАНТАЖУЄ — отже `noindex` у ній не читає ніколи, і адреса, на
# яку хтось послався ззовні, потрапляє в індекс голим URL. Прибрати його потім
# нічим: прибирає рівно той тег, до якого краулер не дійшов. Цей проєкт уже
# наступав на це з `/test`, і з канону 9.16 так тепер написано й у каноні.
#
# Перелік прихованих сторінок живе в `src/lib/config/site.ts`
# (`HIDDEN_ROUTES`); те, що їх тут немає, стереже інваріант у
# `src/beta-checklist.test.ts` — саме на ВІДСУТНІСТЬ рядка.
#
# Групи нижче не успадковуються: краулер обирає одну — найточніший збіг за
# User-agent — і виконує тільки її, ігноруючи `*` цілком (SEO-v8 § 7.2). Тому
# кожна названа група мусить повторювати весь вміст групи `*`, яким би він не
# був. Розбіжність ловить `npm run check:build`.

User-agent: *
Allow: /
